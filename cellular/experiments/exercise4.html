Your rules (JavaScript, function bodies)

Each rule is called as (x, y, a, c). c has: c.gen, c.W, c.H, c.R, c.inZone(x,y), c.randVec(), c.rand(lo,hi), c.at(x,y) (a vector or null), c.nb(x,y) (occupied neighbours, 0 to 8).

collide: different genes land on one cell. a = list of vectors. Return a vector or null (erase).

survive: after the step, for each gene. a = [vx, vy]. Return false to delete it.

spawn: for each empty cell. Return a vector to create a gene there, or null.

(or Ctrl+Enter in a box)
Examples to paste: survive return c.nb(x,y) < 6; (overcrowding deletes), return Math.random() > 0.01; (random death). spawn return c.nb(x,y) === 3 ? c.randVec() : null;.
Zone dashed outline shows c.inZone. Values are in window.signals (F12). Space pauses.
